# 客服副驾 MVP 复盘（收尾版）

2026-11-07 ｜ 内部工作台版 ｜ 状态：MVP 完成，试点数据已回收

---

## 一、要解决的问题

店铺私信咨询量大，客服在"翻知识库、查物流、组织话术"上耗时，新人尤其容易答错政策口径。原计划做成直接对接买家的自动客服，但淘宝/京东不开放第三方消息接口，于是调整为**客服副驾**：不替客服回消息，而是把"可直接复制的话术"和依据放到客服面前，人在环里做最后判断。

一句话目标：**让客服 10 秒内拿到一版能直接用的回复，并且这些使用数据能反过来告诉我们知识库缺什么。**

## 二、做出来的东西

| 层 | 交付 |
|---|---|
| 智能体 | Dify Chatflow，8 个业务分支，输出结构化 JSON（回复/依据/下一步/是否升级/新人解释） |
| 知识 | 11 份知识库文档（政策口径、话术范例、升级规则、不确定回复、短事实、参数、促销、技术排查、快递口径、产品库） |
| 工具 | 库存、物流两个 MCP 服务，支持订单号/运单号查询 |
| 应用 | 网页工作台：工号登录、三栏界面、复制/修改/无用/放弃四种标记、AHT 计时、周报看板 |
| 评测 | 200 条中文题库 + 自动化评测 + Excel 明细 + 20 条回归集 |
| 文档 | 评测报告、MVP 规格、上线路线图、试用说明（docx） |

## 三、数据

### 离线评测（200 条，单轮，pass@1，两轮合并）

- 任务解决率 **84.5%**（338/400），95% 区间 80.6%–87.6%
- 单轮 85.0% / 84.0%；逐题两轮都过 78.5%
- P50 8.9s、P95 12.4s
- 分场景：产品 90%、促销 90%、未知 90%、政策 86%、投诉 85%、技术 77%、物流 70%、闲聊 100%

演进：v3.2 55.5% → v3.5 66.0% → v3.8 68.0% → v4.0 79.5% → v4.6 85.0% → v4.8 84.5%（真检索）

### 线上试点（4 名客服，1 天）

- 147 条会话，118 条有明确标记，采纳 **84.7%**
- 新人 89%，老人 77% / 86% / 86%
- 时延中位 9.3s、P95 13.1s；AHT 中位 17s
- 自动沉淀知识缺口 19 条（缺知识 10、答错 5、话术 4）

### 回归

客服踩过的 20 个坑：**20/20**，平均 8s。

## 四、几个关键判断（也是这个项目最值得讲的部分）

1. **口径比数字重要**。原 README 写 94.2%，实际是"同一条问 3 次取最好"（pass@3）。线上客服只问一次，重试有成本，所以对外只报 pass@1，并且每版至少跑两轮报合并值——v3.7 单次 74.0%，复跑只有 67–69%，一次运行能差 7 个点。
2. **先修链路，再调提示词**。有很长一段时间"知识库明明有内容却答不出来"，根因不是提示词，而是：路由分类器提示词被历史补丁污染 → 知识检索节点根本没执行；全角问号导致召回为空；向量库因磁盘满进入只读、文档索引静默失败；if-else 的 false 兜底没接线，异常分支直接空回答。这些不修，调提示词全是白费。
3. **真检索和内联资料做过 A/B**。向量库只读期间把资料写进提示词，做到 85.0%；修好检索后同题 84.5%，差距在噪声内。结论是保留检索（改知识库不用重导入），内联作为故障兜底记录在案，而不是当成"提升手段"写进简历。
4. **评测集会过拟合**。200 条题里有一部分就是照着失败样例改的，所以 85% 要带"同集"限定；真正的泛化证据是留出集盲测，这件事还没做，报告里如实写了。

## 五、试点暴露的问题

- 物流查询有一段时间只回"我这就查"——MCP 的参数名和工具节点缓存不一致，且工具结果没拼进提示词；已修，但暴露了"工具链路没有回归用例"。
- 客服常把订单号粘在买家原话里、输入框空着，模型就去追问订单号；网关加了自动提取，提示词也补了"已知单号禁止再问"。
- 老人 A1002 采纳率 77%，5 条无用全部是"知识库没有这块内容却硬答"——这类问题靠提示词解决不了，只能补文档。
- 场景下拉几乎没人选（131/147 是"自动"），所以"分场景采纳率"目前没有统计意义。

## 六、下一步（如果继续做）

1. 留出集盲测：另出 40–50 条不参与调参的题，验证 85% 能不能复现。
2. 多轮评测：现有 200 条都是单轮，真实会话里的追问、指代、改口没覆盖。
3. 知识缺口闭环自动化：周报里的缺口直接生成"待补文档"任务，而不是靠人看。
4. 接真实数据：现在物流/库存是 mock，接 ERP 之后才能评估真实可用性。
5. 权限与审计：管理员端、敏感操作留痕（目前所有账号同权限）。
