# 工作台前端设计规格（Figma 用）+ 联调约定

> 目标：你在 Figma 出图，我按图实现；这份文档把**每个框里放什么、什么规则、点了发什么请求**写死，避免出图后返工。

---

## 1. 画布

- 桌面端，基准 **1440 × 900**（最小支持 1280 宽）；
- 8pt 栅格，左右留白 24；
- 单页，无侧边导航；
- 三块：顶栏 56px、主区（左 420 + 右自适应）、底部状态栏 40px。

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 56                                                       │
├───────────────┬──────────────────────────────────────────────┤
│ 左栏 420       │ 右栏 flex                                     │
│ 输入区         │ 结果卡片                                       │
├───────────────┴──────────────────────────────────────────────┤
│ 状态栏 40：本次 42s · 模型 8.9s · 有用/没用 · 备注             │
└──────────────────────────────────────────────────────────────┘
```

---

## 2. Figma 需要出的 6 个 Frame

| 编号 | Frame 名 | 内容 |
|---|---|---|
| F1 | `01-login` | 居中卡片 360×420：工号、密码、登录按钮、错误提示 |
| F2 | `02-workbench-empty` | 三栏空态：左侧输入 + 右侧插画"粘贴买家消息，Ctrl+Enter 生成" |
| F3 | `03-workbench-loading` | 右侧骨架屏（3 行灰条）+ 按钮转圈 |
| F4 | `04-workbench-result` | 右侧完整卡片：回复、依据 chips、动作 tag、三个按钮 |
| F5 | `05-workbench-error` | 右侧红色边框卡片："生成失败（超时）" + 重试 + 手动回复入口 |
| F6 | `06-useless-popover` | "标记无用"弹层：4 个原因 chip + 备注 + 确认 |

可选（第二版）：`07-history` 今日记录列表。

## 3. 左栏：三个输入 + 一个按钮

### 3.1 买家原话（textarea）

| 项 | 规则 |
|---|---|
| 高度 | 最小 3 行（约 96px），可拖到 8 行 |
| 上限 | 500 字，右下角显示 `12/500`，超限变红且禁用生成 |
| 占位 | "粘贴买家原话，例如：我买的显卡什么时候发货？" |
| 计时 | **获得焦点时**记录 `started_at`（只记第一次） |
| 快捷键 | `Ctrl + Enter` 生成；`Enter` 只换行 |

### 3.2 场景（下拉）

选项与值必须一字不差（后端按值路由）：

| 显示 | 传值 |
|---|---|
| 自动识别 | `auto` |
| 产品咨询 | `产品咨询` |
| 物流咨询 | `物流咨询` |
| 政策问题 | `政策` |
| 促销活动 | `促销` |
| 投诉售后 | `投诉` |
| 技术支持 | `技术` |
| 闲聊 | `闲聊` |
| 未知/其他 | `未知` |

默认"自动识别"；文案提示"选了就强制走该场景，不确定就留自动"。

### 3.3 订单号（可选）

- 占位："可留空；涉及查单时再填"；
- 校验：`^[A-Za-z0-9-]{6,32}$`，不合法只提示不阻断；
- 不回显"必填"。

### 3.4 模式切换（新人 / 老人）

- 分段控件，默认"老人"；
- 选择记到 `localStorage`，下次自动带出；
- 新人模式时，结果卡片多显示"为什么这么说"区块（老员工隐藏）。

### 3.5 生成按钮

- 文案："生成建议"；
- 禁用条件：买家原话为空 或 超 500 字 或 正在请求；
- 请求中：按钮转圈，文案"生成中…"，左栏只读；
- 旁边小字提示快捷键。

## 4. 右栏：结果卡片

### 4.1 卡片结构（从上到下）

1. **状态条**：`已生成 · 8.9s`；若员工改过 → 右上角黄标"已修改"；
2. **建议回复**：可编辑文本域（自动增高），默认显示 `reply`；
3. **依据**：chips 列表（`evidence` 每条一个），点开显示全文；超过 3 条折叠"+2"；
4. **动作**：tag 显示 `next_action`；`escalate=true` 时旁边红色 tag"转主管"，否则灰色"无需转主管"；
5. **操作区**：`复制`（主按钮）、`保存修改`（仅在有改动时出现）、`标记无用`（文字按钮）。

### 4.2 三个动作的行为（必须按此实现）

| 动作 | 触发 | 请求 | 之后 |
|---|---|---|---|
| 复制 | 点按钮 | `POST /api/result` `{status:"copied", final_text:当前文本}` | 写入剪贴板，toast"已复制" |
| 保存修改 | 文本与原文不同时 | `{status:"modified", final_text, note}` | 按钮变灰，黄标消失 |
| 标记无用 | 点开 F6 弹层选原因 | `{status:"useless", note:原因+备注}` | 卡片置灰，显示原因 |

原因 chip 与后端 `gap_type` 对应：

| 界面文案 | 传 note 关键词（后端据此归类） |
|---|---|
| 知识库没有 | `没有` |
| 答错了 | `答错` |
| 内容过期 | `过期` |
| 话术不合适 | `话术` |

### 4.3 空态 / 加载 / 失败

- 空态：插画 + 一句操作提示，不放按钮；
- 加载：骨架屏 3 行 + "正在生成…"；
- 失败：红色左边框，标题"生成失败"，副文案给原因（超时/服务不可用），两个按钮：`重试`、`手动回复`（打开纯文本编辑器，提交时 `status:"modified"`、`note:"手动回复"`）。

---

## 5. 底部状态栏

- 左：`本次 42s`（前端计时，从 focus 到点按钮，仅展示）；
- 中：`模型 8.9s`（接口返回 `latency_ms`）；
- 右：`有用` / `没用` 两个小按钮 + 备注输入。

点"有用/没用" → `POST /api/feedback {conversation_id, useful, note}`，按钮变为选中态且不可重复点。

---

## 6. 前端 ↔ 后端：怎么联动

### 6.1 地址与鉴权

- 后端：`http://127.0.0.1:8100`（本机试点，4 人共用这台机器）；
- 已开 CORS，前端任意端口可调；
- 登录拿 `token`，存 `sessionStorage`；之后每个请求带 `Authorization: Bearer <token>`；
- 接口文档：`http://127.0.0.1:8100/docs`（可直接点"Try it out"）。

### 6.2 一次完整交互的请求序列

```
1) 登录        POST /api/login   {agent_id, password}      → {token, name, level}
2) 生成        POST /api/ask     {buyer_message, order_no, agent_level, scene_hint, started_at}
                                 → {conversation_id, reply, evidence[], next_action, escalate, latency_ms}
3) 采纳/修改   POST /api/result  {conversation_id, status, final_text, note, ended_at}
                                 → {ok, aht_seconds, edit_distance}
4) 反馈        POST /api/feedback{conversation_id, useful, note}
5) 离开未操作  POST /api/result  {status:"abandoned"}   ← 页面卸载时用 sendBeacon
```

### 6.3 字段约定

| 字段 | 类型 | 说明 |
|---|---|---|
| `agent_level` | `"new"` / `"veteran"` | 决定是否展示"为什么这么说" |
| `scene_hint` | 上表 9 个值之一 | 传中文值，别传英文 |
| `order_no` | string | 空串表示没填 |
| `started_at` | ISO 8601 带时区 | focus 时刻，如 `2026-11-05T20:52:03+08:00` |
| `status` | `copied` / `modified` / `useless` / `abandoned` | 四选一 |
| `evidence` | string[] | 每条是一段原文，直接展示 |

### 6.4 错误处理（前端按这个显示）

| HTTP | 含义 | 界面 |
|---|---|---|
| 401 | 未登录/过期 | 跳回登录页，提示"登录已过期" |
| 502 | Dify 失败 | 失败态卡片，可重试 |
| 422 | 参数不合法 | 顶部红条提示具体字段 |

### 6.5 出图前可以先看真实数据

`web/mock/ask_response.json` 是一份真实返回（含回复、依据、动作），Figma 里直接照这个填文案，长度最真实。
